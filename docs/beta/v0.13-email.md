**Subject:** ot v0.13.0: AI agents, and one change for scripts

Hi {first name},

Thanks for trying the OTInstaller beta. `ot` v0.13.0 is out. Update with `ot self-update`, or reinstall from
https://otinstaller.com/docs/getting-started.

**One change may affect you.** When `ot` runs without a terminal (a script, a CI job, or an AI agent's shell),
`ot run`, `ot run --all`, `ot playbook` and `ot auto` now stop with `consent_required` before running a tool that
isn't passive, meaning one that goes online, contacts the target or involves a person's details. Add `--yes` to
those commands in your scripts, or set `OT_CONSENT=off` where you don't need the check. Nothing changes when you
run `ot` yourself in a terminal.

**What's new:**

- **AI agents.** `ot mcp` lets Claude, Cursor, Codex and other MCP clients search the registry, install signed tools
  and run them in the same sandbox as `ot run`. The agent has to ask you before any run that touches a target, and
  every run is logged on your machine (`ot mcp audit`). Set it up with `ot mcp install claude` (or `claude-desktop`,
  `cursor`, `vscode`, `codex`, `gemini`), or install the Claude Code plugin:
  `claude plugin marketplace add OTInstaller/agent-plugin`. Details: https://otinstaller.com/docs/agents
- **JSON everywhere.** `--json` (or `OT_OUTPUT=json`) works on every command that prints data, and errors come out as
  one line of JSON. Useful for scripts: https://otinstaller.com/docs/automation
- **For tool authors:** optional manifest fields that agents read, such as input examples, what each output
  carries, how long a run usually takes, whether a run can notify the target, and what an API key costs. Every
  field is described at https://otinstaller.com/docs/manifest. Older `ot` keeps installing tools that use them.

If you try `ot mcp` with an agent, we'd especially like to hear how the consent questions felt: too many, too few,
or unclear. Reply to this email, run `ot feedback "…"`, or open an issue for anything that blocks you:
https://github.com/OTInstaller/feedback/issues
