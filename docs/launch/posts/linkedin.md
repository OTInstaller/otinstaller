> Today we're opening **OTInstaller Registry**: a free, public registry of open-source intelligence tools and
> investigation guides, and `ot`, a command-line tool that installs and runs them.
>
> Investigators, analysts and journalists rely on hundreds of small open-source tools. Each one installs
> differently, many break quietly when a website changes, and none of them agree on an output format. That costs
> hours before the actual work starts.
>
> With OTInstaller:
>
> → One command installs any tool on the registry, on Windows, macOS or Linux
> → Every tool returns the same structured results, so tools can be chained and results kept with their checksums
> → Releases are signed by the author's own build, scanned, and every new publisher is reviewed by a person
> → A nightly test shows whether each tool still works
> → Tools run on your own machine. We never see your targets or your results
> → Guides walk through real investigations and set up the tools they use
>
> We launch with 37 tools and 10 guides, from username and email checks to domain, phone, image and crypto
> investigations, and a clear acceptable use policy: no stalkerware, no credential attacks, no leaked data.
>
> If you build OSINT tools, publishing takes a pull request: sign in with GitHub or GitLab and the registry drafts
> it for you.
>
> It's free and open source. Try it at https://otinstaller.com, and tell us what you'd like to see next.
>
