> Hi all 👋 I've been building **OTInstaller** (https://otinstaller.com) at OSINTverse: a free registry of OSINT tools
> and guides, plus `ot`, a CLI that installs and runs them the same way on Windows, macOS and Linux.
>
> ```
> ot run osintverse-community/holehe e:you@example.com
> ot auto johndoe        # runs every installed tool that takes a username
> ```
>
> Tools run locally in a locked-down container (your targets never leave your machine), releases are signed and
> scanned, and a nightly test shows whether each tool still works. 37 tools and 10 guides so far, including
> sherlock, maigret, holehe, theHarvester and subfinder.
>
> It's free and open source (https://github.com/OTInstaller/otinstaller). I'd really like feedback, and tool authors: I'm happy to help you publish yours.
