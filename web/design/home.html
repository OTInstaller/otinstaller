ot installs a tool once and runs it on your own machine, in a container that cannot read your files. Before anything is listed here it is:

  • pinned to one image digest or wheel hash,
  • signed by its repository's CI and checked before every run,
  • scanned for vulnerabilities, secrets and malware,
  • run once in the same sandbox, and health-checked every night,
  • reviewed by a person the first time a publisher releases.

Install ot

One file. Windows, macOS, Linux.

Then ot doctor tells you whether Docker or Podman and your keychain are ready.

macOS / LinuxWindows
$curl -fsSL https://get.otinstaller.com/ot | sh
What this script does
  1. Downloads ot_0.12.1_linux_amd64.tar.gz from the GitHub release OTInstaller/ot v0.12.1.
  2. Checks its SHA-256 against checksums.txt, and the Ed25519 signature on that file against the published key.
  3. Puts ot in /usr/local/bin or ~/.local/bin. Nothing else is written. Read the script.
