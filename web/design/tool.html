maigret

Builds a profile of a person from a username: accounts on 3,000+ sites and the details they expose.

Community-packaged from soxoj/maigret, pinned to the upstream release on PyPI. Maintain that project? Claim this package.

Run

$ot run osintverse-community/maigret --username jane_doe
$ot install osintverse-community/maigret

Python wheel, run inside a read-only container · network allowed (checks 3,000+ sites) · no API key · about 2 minutes for 500 sites.

$curl -fsSL https://get.otinstaller.com/ot | sh

maigret (community package)

This repository packages github.com/soxoj/maigret for the OTInstaller Registry as osintverse-community/maigret. The tool is the work of its authors, under the MIT licence; this repository only holds the manifest and release workflow.

Report problems with the tool upstream, and problems with the packaging here. If you maintain the upstream project and want to publish it yourself, run ot claim osintverse-community/maigret: the package is transferred to you.

It installs the upstream project's own release from PyPI, pinned by version and hash; nothing here is rebuilt.

Guides using this tool

Username investigation playbook

From a name or one handle to verified accounts across thousands of sites.

beginner · 4 tools

What next

maigret finds accounts, URLs and people. Tools that take those:

account → 6 toolsurl → 9 toolsperson → 2 toolsot pivot results.json

Takes

  • --username username required
  • --site string optional
    Only check this site, such as GitHub
  • --top_sites integer optional
    How many of the most popular sites to check (default 500)

Finds

  • account → 6 tools take it
  • url → 9 tools
  • person → 2 tools

Keys

  • None needed.

Behaviour

  • Does not contact the target
  • Does not log in to accounts
  • Collects personal data

Talks to: 3,000+ public sites (declared egress).
