# IP address investigation playbook

Who holds an IP, what it exposes and what runs next to it, without scanning it.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/ip-investigation) or in your terminal:

```
ot guide read osintverse-community/ip-investigation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
