# Phone number investigation playbook

Parse a number offline, then find accounts and mentions linked to it.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/phone-investigation) or in your terminal:

```
ot guide read osintverse-community/phone-investigation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
