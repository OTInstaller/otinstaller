# Domain investigation playbook

DNS, subdomains, certificates, history and look-alikes of a domain, passively first.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/domain-investigation) or in your terminal:

```
ot guide read osintverse-community/domain-investigation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
