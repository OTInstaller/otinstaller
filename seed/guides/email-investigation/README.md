# Email investigation playbook

Trace a suspicious message and find where an address is registered, without alerting its owner.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/email-investigation) or in your terminal:

```
ot guide read osintverse-community/email-investigation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
