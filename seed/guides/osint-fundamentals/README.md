# OSINT fundamentals

How an open-source investigation runs, from scope to report, and how to stay safe and lawful doing it.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/osint-fundamentals) or in your terminal:

```
ot guide read osintverse-community/osint-fundamentals
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with `ot release <version>`.
