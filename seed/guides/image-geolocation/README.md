# Image verification and geolocation playbook

Check a photo's metadata, find earlier copies, and work out where and when it was taken.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse/image-geolocation) or in your terminal:

```
ot guide read osintverse/image-geolocation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
