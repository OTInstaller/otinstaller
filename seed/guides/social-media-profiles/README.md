# Social media profiles playbook

Collect and preserve what a public profile shows: posts, media metadata and archived copies.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/social-media-profiles) or in your terminal:

```
ot guide read osintverse-community/social-media-profiles
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
