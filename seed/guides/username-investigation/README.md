# Username investigation playbook

From a name or one handle to verified accounts across thousands of sites.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse/username-investigation) or in your terminal:

```
ot guide read osintverse/username-investigation
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
