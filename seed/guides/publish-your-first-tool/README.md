# Publish your first tool

Package a command-line OSINT tool and publish it to the OTInstaller Registry in about 20 minutes.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/publish-your-first-tool) or in your terminal:

```
ot guide read osintverse-community/publish-your-first-tool
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with `ot release <version>`.
