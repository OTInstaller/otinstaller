# Publish a guide

Write, check and release a Markdown guide on the OTInstaller Registry.

Read it on the [OTInstaller Registry](https://otinstaller.com/guides/osintverse-community/publish-a-guide) or in your terminal:

```
ot guide read osintverse-community/publish-a-guide
```

The pages are in [`docs/`](docs/index.md). Corrections and additions are welcome as pull requests; releases are published with the **otinstaller release** workflow.
