# Publish a guide

Guides are versioned Markdown playbooks and references, published from a repository like tools and linked to the
tools they use. Readers find them on the site and read them in the terminal with `ot guide read`.

**Steps**

1. [Set up the repository](01-setup.md)
2. [Write within the content rules](02-content-rules.md)
3. [Release](03-release.md)

This guide is itself published this way: its source is a repository with an `otinstaller.yaml` and a `docs/`
folder.
